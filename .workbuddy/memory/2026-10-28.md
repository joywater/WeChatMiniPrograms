## 朗读音色升级：WechatSI → 预生成 Azure Neural 音频

**问题**：WechatSI 插件 `textToSpeech` 只有 `lang` 参数，音色固定不可调，听感机械。

**方案**：预生成 mp3 打进代码包，本地播放零延迟；插件保留为兜底。

- `scripts/gen_voice.py`（新建，已加 packOptions.ignore）
  - 从 `utils/defaultData.ts` 正则解析 (id, say)，批量合成 → `assets/voice/{id}.mp3`
  - 双 provider：`edge`（免注册，Edge 朗读接口，与 Azure Neural 同源）/ `azure`（官方 API，50 万字符/月免费）
  - ffmpeg 转 24kHz 单声道 32kbps + loudnorm I=-16 LUFS
  - 自动回填 `audio: '/assets/voice/{id}.mp3'`，已填的跳过
  - `--dry-run` 看清单，`--limit N` 试听，`--force` 重生成
- 音色：`zh-CN-XiaoxiaoNeural`（温柔女声，当前），语速 `--rate -8`
- `utils/tts.ts` 重写播放调度：
  - `speak(text, sfx?, localAudio?)` 三级优先：本地 audio → WechatSI 合成 → `onError` 回退合成
  - `preheat(list: {say, audio}[])`：跳过已有本地音频的词条，不浪费插件配额
- `pages/gallery/`：GalleryItem 加 `audio`，wxml 加 `data-audio`，tap 时透传
- 产出：30 条共 364KB，主包 558KB（限 2MB）；响度统一 -16~-18dB 均值、峰值 -2dB

**踩坑**：edge-tts CLI 的 `--rate -8%` 必须写成单参数 `--rate=-8%`，否则 argparse 把它当选项报 exit 2；且可执行文件不在 PATH，脚本改用 `python -m edge_tts`。

**试听页**：`design-assets/voice-demo/index.html`（三音色对比 + 30 条成品，相对路径引用 babyspot 音频）。

**待办**：正式商用前把 provider 切到 `azure`（edge 是非官方接口，商用条款模糊）。

**腾讯云 TTS 踩坑（重要）**：
1. 接口名是 `TextToVoice`，不是 `TextToSpeech`（后者报 InvalidAction）
2. 精品音色 SampleRate 只支持 8k/16k，传 24000 报 InvalidParameterValue.SampleRate
3. 免费资源包需在控制台「语音合成 → 资源包管理」手动领取，否则报 UnsupportedOperation.PkgExhausted
4. 偶发 `502 Bad Gateway`（代理链路抖动），脚本已加 4 次重试，业务类错误不重试
5. 签名 TC3-HMAC-SHA256 用标准库实现，无需装 SDK；脚本已固化
